Getting Started with Vite

            

              Vite (French word for "quick", pronounced /viːt/, like "veet") is a modern build tool designed for developer speed.
            

            

              
# 1. Create a project

              
pnpm create vite@latest my-app --template react-ts

              
# 2. Run dev server

              
cd my-app && pnpm install && pnpm dev

            

            
Why Vite?

            

              Traditional bundlers had to crawl and build your entire application before starting the dev server. As apps grew to thousands of modules, cold starts could take over a minute, and editing code meant waiting seconds for updates.
            

            

              Vite addresses these issues by leveraging native ES Modules in the browser and pre-bundling dependencies with high-performance native tooling (Rolldown / Oxc / esbuild).
            

          


          
          

            
Core Features & Hot Module Replacement

            

              Vite provides instant Hot Module Replacement (HMR) over native ESM. When a file is modified, Vite only needs to invalidate the chain between the edited module and its closest HMR boundary.
            

            

              
// Example HMR Hook in JavaScript / TypeScript:
if (import.meta.hot) {
  import.meta.hot.accept((newModule) => {
    console.log('[hmr] updated module:', newModule)
  })
}

            

            
CSS Code Splitting

            

              Vite automatically extracts the CSS used by modules in an async chunk and emits a separate file for it. The CSS file is automatically loaded via a <link> tag when the associated async chunk is loaded.
            

          


          
          

            
Universal Plugin API

            

              Vite plugins extend Rollup's well-designed plugin interface with a few extra Vite-specific options and hooks (such as config, configResolved, configureServer, and transformIndexHtml).
            

            

              
// Sample Custom Vite Plugin
export default function myVitePlugin() {
  return {
    name: 'vite-plugin-custom-transform',
    transform(code, id) {
      if (id.endsWith('.custom')) {
        return { code: `export default ${JSON.stringify(code)}` }
      }
    }
  }
}

            

          


          
          

            
Environment API & Server-Side Rendering

            

              The Vite Environment API (introduced in Vite 6) allows frameworks to define custom execution environments like client, SSR, Edge runtime (Cloudflare Workers, Deno, Workerd), and React Server Components (RSC) within a single unified dev server.
            

          


          
          

            
@vitejs/plugin-legacy

            

              Vite's default browser support target is modern browsers supporting native ESM. The @vitejs/plugin-legacy package emits fallback SystemJS chunks and conditional polyfills for legacy browser targets without penalizing modern users.
